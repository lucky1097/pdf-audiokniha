# Brief E1: title and AI notice tags in MP4 files, in core

## Goal
The iPhone app joins sentences into one .m4a with Apple's encoder, which writes no tags. The exported audiobook must
still carry its title, author and the AI notice (the Supertonic 3 licence, OpenRAIL-M, requires generated content to
be labelled; the web export writes it with mediabunny). Add iTunes-style tags to `packages/core/src/mp4.ts`, written
in the same pass as the chapter list.

## Files
Read: CLAUDE.md, packages/core/src/mp4.ts (`withChapters`, box walking, offset shifting), packages/core/test/mp4.test.ts,
apps/web/src/lib/export.ts (`AI_NOTICE` text and how tags are set there).
Change only: packages/core/src/mp4.ts, packages/core/src/index.ts, packages/core/test/mp4.test.ts, apps/web/src/lib/export.ts.

## Behaviour
- `withChapters(file, chapters, tags?: Mp4Tags)` where
  `export interface Mp4Tags { title?: string; artist?: string; album?: string; comment?: string; genre?: string }`.
  Export `Mp4Tags` from index.ts.
- Move `AI_NOTICE` from apps/web/src/lib/export.ts into core (export it from index.ts; the web file imports it).
- With tags: the inserted bytes are the chpl box plus a `meta` box, both inside the same udta (one insertion, so the
  existing offset shifting covers both):
  `meta` = full box (size, "meta", 4 bytes version/flags = 0) containing
  `hdlr` = size, "hdlr", version/flags 0, pre_defined 0 (4 bytes), handler_type "mdir", 12 bytes: "appl" then 8 zero
  bytes, name: a single 0 byte; and `ilst` containing one box per non-empty tag:
  "©nam" title, "©ART" artist, "©alb" album, "©cmt" comment, "©gen" genre ("©" is byte 0xA9; write the type as
  bytes [0xA9, n, a, m] etc., not as UTF-8), each holding one `data` box: size, "data", 4 bytes type indicator
  0x00000001 (UTF-8), 4 bytes locale 0, then the UTF-8 value.
- If udta already has a `meta` box, do not add a second one: throw an Error "file already has tags" only when tags
  were passed (the iPhone files have none; keep it simple).
- Without tags: output byte for byte as today (the existing tests must pass unchanged).
