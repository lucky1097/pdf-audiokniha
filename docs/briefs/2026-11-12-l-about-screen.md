# Brief L: "O appke" screen with privacy, AI notice, voice terms and licences

## Goal
Before the App Store release the iPhone app needs one screen that a user (and Apple's reviewer) can open from the
library: what happens with their data, that the voice is AI, the voice model's use restrictions (the OpenRAIL-M
licence requires us to pass them on as terms of use), and the licences of what the app ships. The app is now called
"Audify".

## gen-licenses.mjs
Node ES module, run from the repo root as `node apps/mobile/scripts/gen-licenses.mjs`. Writes
apps/mobile/src/generated/licenses.ts with a header comment "Generated by apps/mobile/scripts/gen-licenses.mjs; do
not edit." and `export const LICENSES: { name: string; licence: string; text: string }[]` in this order:
1. Supertonic 3 (Supertone Inc.), "OpenRAIL-M", text = licenses/supertonic-3-OpenRAIL-M.txt
2. ONNX Runtime, "MIT": node_modules/onnxruntime-react-native has no LICENSE file; use the standard MIT text with
   "Copyright (c) Microsoft Corporation".
3. PDF.js (Mozilla), "Apache-2.0", text = node_modules/pdfjs-dist/LICENSE
4. React Native (Meta), "MIT", node_modules/react-native/LICENSE
5. React (Meta), "MIT", node_modules/react/LICENSE
6. Expo, "MIT", node_modules/expo/LICENSE
Fail with a clear message if a file is missing. Use JSON.stringify for the strings. Normalise CRLF to LF.
